# 響應式與無障礙

## 寄語輪播

- 桌機與手機都維持每組最多四張卡片；手機縮小間距與卡片內距，而不是改回無上限縱向列表。
- 左右按鈕保留可見焦點與 `aria-label`，目前組以外的內容使用 `aria-hidden` 與 `inert`。
- 桌機為箭頭保留左右安全區；700px 以下將兩枚箭頭固定移至輪播下方，避免遮住卡片文字。
- 寄語分組疊放在同一個 CSS Grid 軌道，讓最高組別保留版面高度，避免切換時控制項與頁面內容產生垂直位移。
- 觸控只在明確的水平滑動時換組，避免攔截頁面的垂直捲動。
- reduced-motion 模式直接完成切換，且只有一組時隱藏無作用的控制。
- 主要內容面板進入視窗時會柔和浮現並在離開後復原；reduced-motion 模式直接顯示，不播放重複位移。

## 垂直閱讀與高度

- 所有主章節都使用一般文件流，沒有 scroll snap 或作品區 sticky 鎖頁。
- 全站宣紙使用獨立的 `position: fixed; inset: 0` 裝飾層，`pointer-events: none`；不使用行動瀏覽器相容性較不穩定的 `background-attachment: fixed`。
- `body` 保留同色 fallback，即使手機動態工具列改變可視高度，也不會在背景層邊緣露出白色空隙。
- 開場仍使用 `100vh` 與 `100dvh`，因它是唯一真正滿版的 dialog。
- 理時序桌機至少為 `calc(100svh - 82px)`；手機解除最低滿版高度，讓內容自然撐開。
- 桌機 main 保留 96px 左側空間；900px 以下則對應 82px／70px 上方資訊列。

## 手機版

- 全站章節使用垂直捲動；觀芳華展廳內仍可水平滑動換作。
- 理時序強制 `<br>` 在 768px 以下隱藏，引文自然換行。玻璃框使用父層可用寬度，標題內容預留章節標籤高度，避免「01 理時序」與「四時流轉」重疊或內文在右側被裁切。
- 所有作品使用共同的 16:9 展示框；目前第 24 張正式作品依原比例顯示，後續作品的裁切、滿版或疊字位置需在素材到位後逐張驗證桌機與手機。
- 作品文案最多為展廳內容寬度的 88%，靠右對齊。
- 作品進度環位於「作品展示」標題列右側，桌機與手機皆保留小環、節氣名與編號。
- 展廳使用 `touch-action: pan-y`，上下捲動不應被誤判成換作；水平滑動超過 50px 才切換。
- 作品區沒有額外的下一章按鈕；向下自然捲動即可接續繪春信。
- reduced-motion 與一般模式都使用相同的自然章節高度，不要求長距離捲動。

## 寄語卡片

- 561px 以上每組使用固定的雙欄兩列：左上、右上、左下、右下依序產生柔和垂直落差；四張卡片等寬等高，六組排列一致。
- 560px 以下改為單欄；卡片使用手機專用固定高度與較小字級，署名固定在相同的右下基準，正式留言不得裁切、溢出或覆蓋署名。
- 新增或刪除卡片仍由 JavaScript 每四張自動分組，不需手動建立分頁。
- 寄語為一般靜態文件內容，不自動捲動、不使用跑馬燈，也不要求額外鍵盤操作。

## 委託名單

- 桌機將 36 人平均分在三個等寬紙框，每框 12 人；框面沿用寄語卡片的圓角、淡紙色與內層亮線。
- 700px 以下三框改為垂直排列，每框內使用兩欄名單，避免單一頁面被 36 行文字過度拉長。
- 三組皆以語意化清單呈現；正式暱稱換入時只替換各 `<li>` 文字，不改動排列結構。

## Dialog 與焦點

- 開場使用原生 `dialog`／`showModal()`；選單使用非模態 `dialog`／`show()`，讓抽屜開啟時仍可捲動並更新目前章節。
- 開場使用 `aria-labelledby`、`aria-describedby`；Esc 以靜音方式進入。
- 選單以隱藏的 `#menuTitle` 提供 `aria-labelledby` 對應名稱。
- 選單與開場關閉後，焦點回到 `#menuToggle`。
- 選單按鈕保留 `aria-controls`、`aria-expanded`；目前章節以 `aria-current="page"` 標示。

## 作品可存取性

- 24 件作品保留正常 DOM 順序；非目前作品設為 `aria-hidden` 與 `inert`，換作完成後只留下唯一可讀作品。
- 展廳進度環與重複節氣資訊設為 `aria-hidden=true`；正式節氣名稱仍存在目前作品的 `h2`。
- `.carousel-viewport` 可聚焦，左右方向鍵可切換作品；動畫或載入中的再次操作不排隊，避免稍後非預期換作。
- 手機箭頭縮小的是可見圓面與 SVG，44px 的實際觸控區仍保留；任何新增的個別作品視覺效果都不得讓控制在輔助技術中失去可用性。
- 寄語的章節玻璃框包住標題與完整輪播內容；560px 以下字卡改為較小字級與內距的單欄，同一斷點內卡片尺寸一致。
- 載入狀態透過畫面外的 `aria-live="polite"` 向螢幕閱讀器回報，不在作品畫面增加狀態文字；作品不自動輪播。
- 裝飾層大多為 `aria-hidden` 或 `inert`，且不接收 pointer events。
- 圖片 `alt` 仍是暫時文字，正式上線前必須補寫。
- 理時序個別節氣是不可聚焦的展示文字；節氣環全自動輪轉，不要求 pointer、觸控或鍵盤操作，並以 `aria-label` 說明為自動循環圖。

## 修改檢查

- 約 320px 窄寬、一般手機、平板與大桌面都能到達所有內容。
- 固定 header 不遮住導覽目標；頁面不產生水平捲軸。
- 鍵盤可開關選單並定位章節；焦點不會因捲動狀態更新而被搶走。
- 使用 Esc、遮罩與關閉鈕後 class、ARIA 與焦點皆正確。
- reduced-motion 下沒有被延遲動畫卡住的內容。

修改斷點、固定 header、手機版面、捲動方式、dialog、焦點、ARIA、`inert` 或 reduced-motion 時更新。
