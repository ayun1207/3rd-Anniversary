# 動畫與互動

## 現行 GSAP 動畫邊界（2026-11-13）

- 所有現行動態統一由 GSAP 核心管理，包含章節、導覽、按鈕、入口、節氣環、作品、寄語、手機名單及音樂淡入。`html.gsap-motion` 停用既有 CSS animation／transition 的時間控制，CSS 繼續提供靜態材質、幾何與狀態樣式。
- `navigateToSection()` 先以 220ms 淡出目前章節，交接狀態後以 480ms 淡入新章節。快速點選會取消舊時間軸，以最新要求為準，完成後清除透明度行內樣式。
- 章節只動畫透明度；`.chapter-page-fit` 的 transform 專門負責既有置中縮放。
- Vue 導覽元件管理自己的指示線，以 380ms 移至目前章節下方，並在卸載時清理 tween、ResizeObserver 與事件。
- 按鈕點擊以獨立 `--press-scale` 提供 260ms 回饋，結束後移除屬性。首頁入口排除此通用回饋。
- 首頁入口使用單一 timeline：標題與拼圖以 1050ms 原地淡出，入口文字以 900ms 放大至 1.38 倍，750ms 時開始 400ms 淡出；1150ms 時無停頓接續 1650ms 圓形揭露。按鈕本體不縮放、不位移。
- 圓形遮罩從完全遮蔽的 -48px 半徑連續擴展，最終半徑依入口至最遠視窗角落計算。封面底色在交接前固定，避免切換根節點狀態時突然變色；不另加實色過場幕。擴展範圍到達節氣環中心並露出部分環體後才啟動，取代固定延遲；context 在結束後還原暫時樣式。
- 節氣環透過入口 context 的 `ignore()` 啟動，讓中央文字淡入、逐字與後續節氣排程獨立持續，避免入口結束時一併被復原或中斷。
- reduced-motion 下章節直接交接，入口直接完成；中途變更設定也會收束至正確最終狀態。
- 作品下載與解碼完成後，使用 GSAP 在完整舊圖上方以 680ms 疊入新圖，圖面與覆圖文字共同淡入，完成後移除舊圖。保留 `turnVersion`、`isAnimating` 及最新方向佇列，取消時 kill timeline 並清除暫時透明度；舞台不再使用舊節氣變色底與紙紋。
- 寄語以 GSAP `xPercent` 在 680ms 內整頁交接，保留版本及動畫鎖；復原時清除 transform、同步 inert／aria-hidden，維持唯一目前頁。
- 節氣指針以 520ms 更新角度，2200ms 自動節奏與 120ms 預覽延遲使用 `gsap.delayedCall`。中央文字淡入、96ms 逐字、季節色溫及尾跡亦由 GSAP 管理，離章及頁籤隱藏時取消排程。
- 入口圓形擴張由 GSAP 直接更新遮罩半徑，手機名單以 560ms 更新位移變數，音樂音量以 1800ms 淡入。封面拼圖保持靜態；內頁使用三組背景圖，新圖解碼後以 700ms 疊入，動畫完成再移除舊層，reduced-motion 直接交接。
- 資源等待逾時與載入排程仍可使用原生計時器，這些計時器不控制視覺動畫。

下方保留各區既有細節。涉及舊長頁、選單抽屜與捲動進場的描述，以本節及 `navigation.md` 的固定章節設計為準。

## 銘同錄結語彩蛋

- `src/components/EpilogueGem.vue` 完整管理寶石入口、原生 modal dialog、開關狀態與 GSAP 動畫，讀取既有 `currentChapter`，只在 `thanks` 章節顯示右下角入口。
- 寶石依銘同錄主體框的實際右下角定位，下方保留 12px 間距；下方不足時移至右側，兩側皆不足時置於框內角落並留間距。間歇輕搖約 1 秒，每次之間停留 4.8 秒；開啟結語、離開章節、背景分頁與 reduced-motion 時停止並歸位。
- 點擊後周圍以 950ms 降低亮度，不透底的灰綠框以 1100ms 從寶石中心展開。結語使用暖白字及輕微高光、柔影，避免多層字緣疊加。展開只動畫 opacity 與 scale，不使用全畫面即時模糊。
- 結語沿用既有兩句，以固定完整排版中的字元透明度逐字顯現，前段在每字約 40–180ms 間連續變速，標點短暫停留；「亦願與君偕行」逐字放慢至約 220–470ms 並延長淡入，整段約 8 秒。手機依可用寬度換行，文字以靜態段落承載書寫動畫。
- 點擊空白、關閉按鈕或 Esc 可柔和關閉，完成後焦點回到寶石。開關期間保留狀態鎖並取消過期 timeline，重開從頭書寫。
- 原生 dialog 提供焦點限制與背景 inert；完整結語另供輔助技術讀取，逐字動畫不逐字播報。reduced-motion 直接顯示全文，中途切換設定也會完成當前動畫。
- 結語使用辰宇落雁體，`npm.cmd run optimize:font` 會擷取 `EpilogueGem.vue` 的 `lines`，納入作品文字字體子集。寶石以藍、金、粉四個明暗切面、中央亮稜與邊緣反射呈現厚度。

## 寄語分組切換

- 每四張寄語卡片形成一組；新舊組以 680ms 完整橫向交接，卡片與文字一起移動。兩組保持超過一個組寬的安全間距，不使用 opacity，也不在移動時互相覆蓋，因此玻璃卡顏色維持固定，不會殘影、先亮後暗或只剩文字抖動；首尾可循環，但不自動播放。
- 快速操作由動畫鎖與版本檢查保護，觸控只在明確的水平滑動時換組。
- prefers-reduced-motion 下取消位移並直接復原到最終狀態。

## 動態原則

- 整體安靜、柔和、稍慢，動態用來建立環境感與閱讀回饋，不用來模擬投影片換頁。
- 不做頁面離場、整頁上移或強制 scroll snap；作品只在有邊界的橫向展廳內換作。
- 內容顯現以原地透明度為主；動畫停用時幾何位置必須完全正確。
- 自動輪轉、快速操作、選單操作與 reduced-motion 都不能留下過期狀態。

主要內容面板由 `IntersectionObserver` 判斷是否進入視窗，以短距離位移與透明度柔和浮現；離開視窗後會復原，因此向上或向下再次瀏覽時都能重播。效果只套用章節面板與作品展廳等主要區塊，不綁定章節 `active` 狀態，也不逐行驅動文字，以免章節交界處閃爍或造成過度動態。

節氣環目前指向的節氣以霧白字、稍高字重、貼近字形的深色清晰邊與極淡季節色光澤提高辨識度；不使用底色或外框，以免破壞圓周文字的連續感。效果跟隨既有 `is-previewing` 狀態，不新增滑鼠互動，也不改變節氣環的自動時鐘節奏。

節氣環指針末端與作品進度小環共用低彩度三色切面的菱形寶石；指針細線使用外圈同系的季節色反射與柔光，僅提升辨識度，不改變既有自動輪轉節奏。

## 捲動更新與換作取消

- scroll／resize／pageshow 只排入一個 `requestAnimationFrame`，由 `scrollFrame` 防止同一畫格重複計算。
- 作品區採自然頁流，滾輪不攔截、不觸發換作；scroll 更新只用於目前章節與左側資訊軌狀態。
- 作品換作由 `isAnimating`、`turnVersion` 與 `turnAnimations` 管理；取消後由 `finishPageTurn()` 重建唯一目前作品。
- 換作期間再次手動操作時，會保留最新一次方向，在目前圖片與動畫完成後立即接續；不累積多次指令，也不讓過期的非同步結果覆蓋最新狀態。
- `prepareSlideImage()` 管理按需載入與解碼 promise；換作不在目標圖準備完成前撤除目前作品，載入錯誤則使用預留狀態收束。
- 單次圖片等待上限為 8 秒；逾時時保持目前作品並解除操作鎖，不在背景載入完成後自動換作。
- `cycleRotation` 累積正負 15 度，避免第 24 件回第 1 件時視覺倒轉。
- 節氣輪轉保留 `solarPreviewVersion`、`solarAutoplayTimer`、`solarTypingTimer`、`solarHoverTimer`，防止重啟或頁籤切換後產生殘字。
- 節氣時鐘在離開畫面後仍持續推進自身索引；只有畫面外不需要的逐字、尾跡與 24 個標籤 class 更新會暫停，回到附近時立即同步目前節氣。固定背景時間環不參與這套狀態。
- 音樂保留 `musicRequest`，避免舊播放 promise 或淡入 frame 回寫新狀態。

## 手機動畫效能

- 固定的大型時間環在桌機與手機都不得隨章節切換改變 transform、透明度或色彩，也不跟隨節氣描邊位置變化。
- 手機封面可顯示完整時間環；進站後停用會建立超大離屏紋理的 SVG mask 與刻痕，只保留固定環體。桌機版使用與首頁相同造型、但透明度更低且不使用濾鏡的靜態版本。
- 長頁面中的大面積玻璃框不使用即時 `backdrop-filter`；透明底色、折射漸層、邊框與內層高光仍保留，因此效能簡化不應看起來像完全不同的主題。
- 持續動畫必須在頁籤隱藏、`prefers-reduced-motion` 或其視覺區塊遠離畫面時停止非必要工作；狀態推進與視覺繪製分開管理。
- 新增動畫優先使用 opacity 與 transform；若效果必須使用 filter、mask 或大面積 fixed layer，需先做手機開關對照測試，再決定是否提供輕量版本。手機主要章節內容直接顯示，不套用重複捲動浮現，以免多個離屏面板長期佔用合成層。

## 全域按鈕與開場回應

- 一般按鈕點擊播放 220ms 的 `scale: 0.97 → 1`；`#enterExhibition` 排除。
- 開場指標距入口 320px 內，經 smoothstep 曲線轉換亮度與文字縮放；不移動實際點擊區。
- 接近反應 450ms，遠離 850ms；鍵盤、滑鼠與觸控路徑分開。
- 點擊「入新章」後，標題、副標與封面拼圖原地淡出，入口文字放大成為焦點；入口完全淡出後，才在最上層的真實封面打開圓形缺口。不得改以裁切 `main`、`#intro-page` 或導覽列模擬擴張，也不得加入實色過場幕；退場不使用全畫面 blur、brightness 或 saturate，焦點仍回到導覽首頁按鈕。
- 節氣環啟動依實際擴展半徑與環體位置判定；啟動後其餘擴張照常完成，不縮短整體轉場。

## reduced-motion

- 章節導覽立即定位。
- 作品換作立即完成，但仍更新節氣、編號、環角度與可存取狀態。
- 停用進度環旋轉過渡、選單、按鈕、節氣環與開場效果等主要 transition／animation。
- 節氣文字直接完成，不逐字輸出。
- 背景時間環本來即為靜態，不需另外切換狀態。
- 首頁寶石色霓光完全隱藏，不保留沿軌道位移。
- 主要內容進入視窗時直接顯示，不套用位移或透明度過渡。
- 開場進站略過收束與展開動畫，直接進入頁首並恢復正確焦點。

## 修改檢查

- 頁面與作品區可自然上下捲動，滾輪不會改變目前作品。
- 快速切換或 24→1 時，進度環、節氣名稱與唯一目前作品保持同步。
- 無快取、慢速網路與缺圖狀態下，換作期間都不出現空白畫面或永久等待。
- 自動切換或頁籤恢復時不留下殘影、舊文字或重複計時器。
- 不用 transform 同時負責版面定位與多組動畫。
- reduced-motion 保留完整功能與內容。
