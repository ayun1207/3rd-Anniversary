# 目前狀態

## 桌機發布前驗證（2026-11-14）

目前採用固定上方導覽與六個獨立章節，背景分三組圖片，首頁使用 35 圖片構圖，銘同錄另有寶石結語彩蛋。以下驗證以當日正式 Vite 建置為準。

- 首次 HTML 已為其他五章加入 `hidden`／`inert`，避免 JavaScript 初始化前提前請求繪師、題記及寄墨箋圖片。另預載首頁入口使用的辰宇落雁體。
- Chromium 桌機 1440×1000，無快取、8 Mbps、80ms 延遲、4 倍 CPU 降速，最新一次首屏內容約 1.14 秒、load 約 1.72 秒；兩套主要字體約 0.91–0.95 秒載入。測得 CLS 約 0.00004。時間僅代表本機模擬環境。
- 同一節流條件的快取對照，在新增辰宇落雁體預載前，首訪 FCP／load 為 1.11／1.91 秒，再訪為 0.34／0.46 秒，資源傳輸約 1.32 MB 降至 2.7 KB。
- 24 張作品連續切換一輪，皆載入完成且只保留一張目前作品；每次約 0.71–0.88 秒，包含既有 680ms 淡入。快速連點後仍維持唯一目前作品。
- 桌機入口與節氣環採樣皆無超過 34ms 的幀間隔。4 倍 CPU 降速的首次初始化曾有約 0.53 秒長任務，低階硬體仍需實機確認。
- 透過 Chromium 實際字形來源確認文楷、辰宇落雁體與「猧」的 Chiron 補字。模擬主字體下載失敗後，回退字體可正常顯示且解除等待狀態。
- 六章連續導覽、結語、鍵盤與 reduced-motion 檢查通過，檢查期間無 JavaScript 錯誤。內容驗證仍有兩項既有提醒，即作品 alt 及網頁 title 尚為暫用文字。
- 本機正式靜態伺服器以 50 併發執行 1,000 次資產請求，0 錯誤，回應大小皆正確，p95 約 81ms。這是本機檔案服務測試，線上 CDN 容量需部署後確認。

### 預定使用 Cloudflare Pages

- 連接目前 GitHub 儲存庫與 `main`，建置指令為 `npm run build`，輸出目錄為 `dist`。建議 `NODE_VERSION=24`，`VITE_BASE_PATH` 使用 `/` 或留空，沿用目前 Vite 預設。
- 本機根路徑已實測，既有 GitHub Pages 流程繼續使用 `/3rd-Anniversary/`。網站建置約 75 檔、8.6 MB，最大檔案約 700 KB。
- 尚未建立 Cloudflare Pages 專案或發布網址。部署後須重新驗證真實網路冷載入、快取回應及字體資產狀態。
- 設定依據為 [Cloudflare Vue 部署說明](https://developers.cloudflare.com/pages/framework-guides/deploy-a-vue-site/) 與 [Pages 平台限制](https://developers.cloudflare.com/pages/platform/limits/)。
