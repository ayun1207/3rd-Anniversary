# 頁面與導覽

最後核對：2026-11-04

## 頁面結構

網站以六個獨立章節瀏覽，同一時間只呈現所選章節，透過常駐上方導覽切換。各章完整構圖由 `.chapter-page-fit` 等比例縮放並置中於固定視窗，整頁停用上下捲動。每章保留原本主體框與「兩位數編號＋章名」小標格式。

| section key | DOM | 左上標籤 | 內容 |
| --- | --- | --- | --- |
| `intro` | `#intro-page` | 理時序 | 大標、引文與節氣環 |
| `gallery` | `#gallery-page` | 觀芳華 | 大標「作品展示」與獨立的 24 件橫向循環展廳 |
| `text` | `#text-page` | 繪春信 | 繪師資訊，內容待補 |
| `planning` | `#planning-page` | 籌花事 | 設計理念，內容待補 |
| `messages` | `#messages-page` | 寄語 | 可變數量的留言與署名卡片 |
| `thanks` | `#thanks-page` | 謝花人 | 三個等寬紙框的 36 人委託名單；暱稱待替換，章節編號為 06 |

不要自行在選單名稱前加入數字，也不要混淆繪春信與謝花人。

銘同錄目前僅呈現委託名單，結語區已暫時移除，主體框按名單本身的尺寸置中。

## 固定導覽與章節定位

- 新增常駐上方章節列，由 `src/components/ChapterNavigation.vue` 管理；桌機直接顯示六章，900px 以下以目前章節按鈕展開。選章後收合，支援 Esc、外側點擊與鍵盤焦點離開收合。
- 章節狀態由 `script.js` 的 `setCurrentSection()` 寫入共用 `currentChapter` ref；Vue 導覽只讀取該狀態，並呼叫 `navigateToSection()`。非作用中章節使用 `hidden` 與 `inert`，保留 DOM 與作品、寄語切頁狀態，但不參與排版與鍵盤導覽。
- 封面期間章節列隱藏。原左側寶石按鈕移至章節列最左端，僅提供返回理時序功能；手機章名由章節展開按鈕顯示。

- 舊左列已清空並隱藏，桌機與手機都由上方 Vue 導覽提供選章；主體框置中於導覽下方的完整可用寬度。
- 選單呼叫 `navigateToSection(pageName)`，切換可見章節、回到頁首並將焦點交給該章節，不再跨長頁平滑捲動。
- 主體框切頁由 GSAP 以 220ms 淡出、480ms 淡入交接，快速連點採用最新選取，reduced-motion 下立即顯示。作品換圖時右上小環持續顯示，只更新節氣文字與指針。
- `fitCurrentChapter()` 在選章、內容尺寸及視窗變化時重新計算縮放比例。章名、`aria-current` 與 body 狀態由選章變更。
- 目前章節由上方導覽的 active 狀態表達；手機以目前章節按鈕顯示名稱。
- 左列滑動浮標及對應捲動監聽已移除。
- `.active` 與 `hidden`／`inert` 共同標示目前顯示章節。節氣環離開理時序時暫停，返回時恢復自動運行。
- 導覽不寫入 URL hash，也不建立瀏覽器歷史項目。
- 瀏覽器的自動捲動位置復原已停用；重新整理後顯示封面，按下進入時會明確回到理時序頁首，不沿用重新整理前的位置。

## 導覽按鈕與配色

- `#chapterHome` 使用原寶石 SVG，由 Vue 管理點擊並呼叫 `navigateToSection('intro')`。入口結束後焦點也移至此按鈕。
- 舊 `#siteMenu` 抽屜、開關事件與公開函式已移除。手機仍可使用章節展開按鈕選章，支援 Esc、外側點擊與焦點離開收合。
- 章節列沿用原選單深午夜藍漸層，文字使用 `--time-ink-primary` 與 `--time-ink-secondary`，目前章節保留寶石色細線。

## 資訊章節

- 三節都使用 `.info-page` 與 `.text-container`，位於作品長頁之後。
- 三節使用章節編號、細欄線與交錯標題位置；進場只做淡入，不再上下位移。
- 三節內容尚未完成，不要代替使用者發明介紹、名單或企劃文字。

## 修改檢查

- 選單與常駐導覽能切換正確章節；每次只有一章可見，捲動到底不會露出其他章節。
- 選章後左上標籤、選單 active 與 `aria-current` 同步，章節內捲動不改變選取。
- 左側資訊軌或上方橫條不遮住章節內容；桌機 main 保留 92px 左側空間，平板與手機保留對應上方空間。
- 寶石按鈕回到理時序，手機章節列展開與收合不造成頁面水平位移。
