# 開場與背景

最後核對：2026-11-13

## 現行內頁背景（三組章節底圖）

- 內頁已改為固定章節導覽，由 `src/components/ChapterBackground.vue` 讀取導覽共用的 `currentChapter`，完整管理底圖載入、解碼、圖層與 GSAP 交替。
- 理時序、觀芳華使用 `artwork-originals/32.png`；繪春信、籌花事使用 `33.png`；寄墨箋、銘同錄使用 `34.png`。
- 原圖以 `npm.cmd run optimize:backgrounds` 輸出至 `images/backgrounds/`，提供 1280px 與 2400px WebP，透過 `srcset` 依視窗及像素密度選擇。圖片以 Vite import 處理正式部署子路徑與內容雜湊。
- 同組切章不更換背景。換組只在新圖解碼完成後疊入，保留上一層至動畫結束，並以版本檢查防止舊請求覆蓋最新章節。初次只準備第一組，其他組依選章載入，瀏覽器快取負責重訪重用。
- 淡化集中在 `style.css` 的 `--chapter-background-art-opacity` 與 `--chapter-background-veil`，底圖滿視窗 `cover`，手機會依比例裁切。
- 內頁不顯示舊環境漸層、時間大環與左列。舊寶石串列及書籤裝飾已從 HTML 移除，上方 Vue 導覽保留；主體改以完整可用視窗寬度置中。
- 主體玻璃以淡綠透明面、細亮邊、內部反光及低強度色彩陰影浮於圖片前方。桌面與手機統一停用大型背景模糊，維持切章前後一致的背景透視，避免父層淡入完成後出現突然霧化；主體標題、小標、理時序內文與外圈節氣文字使用深綠，圖片內建文字沿用素材。
- 背景只在換組時執行 700ms 透明度動畫，沒有常駐動態。reduced-motion 直接交接，中途啟用也立即收束。
- 封面使用 `artwork-originals/35.png` 的透明拼圖，桌機左文右圖，900px 以下上文下圖；原本大環、指針與專屬 SVG／CSS 已移除。
- 封面標題以不透明暖白字面、短距離的高光與明暗側面呈現浮雕厚度，搭配單層短柔影；移除透明漸層字面與遠距離疊影，避免字影透入筆畫形成模糊。手機採更短的側影，字體、尺寸與排版保持原樣。

## 歷史設計方向

整體改採 **歲序迴環（Temporal Sculpture）**。主色為深靛藍、藍灰與近黑海軍藍，以霧青、香檳金、琥珀與銀藍紫作低飽和的局部反光。視覺核心是一件位於內容後方、超出視窗裁切的大型時間環形雕塑；它應具有霧面金屬、深色玻璃與細緻邊緣光的物理層次，但不可呈現成宇宙、星空、科技傳送門或四等分彩虹。二十四節氣仍是內容主題，背景不再使用花草、水墨、宣紙或古風山水作為主要語言。

## 開場封面

`#entrance` 是全螢幕原生 dialog，文案為：

- 主標：`霓影流轉 四時成章`
- 副標：`踏歲偕行續年華 來春共赴啟新篇`
- 入口：`入新章`

主、副標目前不含標點，不要自行補上。

封面保留既有灰綠背景配色、文字與入口互動，搭配透明拼圖：

| 元素 | 主要 hook | 內容 |
| --- | --- | --- |
| 環境色 | `.entrance`、`.site-paper-background` | 延續既有深色到灰綠的環境漸層與局部微光 |
| 版面 | `.entrance-layout` | 桌機雙欄、手機單欄，圖文以實際版面空間分隔 |
| 透明拼圖 | `.entrance-art` | 35.png 輸出為 900px、1800px WebP，保留 alpha，以 `srcset` 選擇素材，完整顯示正方形構圖 |
| 內容軸線 | `.entrance-content::before` | 細直線建立現代編輯排版的對齊基準，不使用額外裝飾文字 |

主標、副標與入口位於桌面左欄，圖片位於右欄。手機文字位於中上方、圖片位於中下方，使用自適應圖片尺寸與欄間距保持分離。短橫向視窗收緊文字字級與入口內距。入口沿用原有指標距離互動，開場啟用時隱藏後方章節與導覽。

點擊入口時，主標、副標以既有 GSAP 時序淡去，拼圖以 700ms 淡出。入口退場後，由入口中心擴張既有圓形遮罩進入內頁，節氣環的啟動與文字顯現維持原時序。圖片只參與退場透明度動畫。

圖片以 `npm.cmd run optimize:backgrounds` 更新至 `images/backgrounds/35-900.webp`、`35-1800.webp`，約 88KB／206KB。圖片採 eager 與高優先載入，背景不執行常駐動畫。

## 防止重新整理閃頁

- HTML 初始帶 `html.entrance-pending`。
- 此狀態隱藏 `.site-header` 與 `main`，並使用與封面接近的底色。
- 封面初始、開啟與關閉後都保留穩定的瀏覽器滾軸槽位，避免恢復頁面捲動時將置中畫面往左推移。
- JavaScript 開啟 dialog 後，在下一個 animation frame 移除此 class。
- 不要提前移除 class，也不要只靠 script 載入後才新增，否則會再次短暫閃出理時序。

## 理時序背景

- 理時序、觀芳華與後續章節共用同一個固定時間雕塑背景；章節本身維持深色透明玻璃表面。
- 理時序原有的漂移霧光、底部海波紋、四季飄葉與滑鼠推動效果已移除，不再建立額外的背景動畫或指標監聽。
- 節氣環本體、自動輪轉、指標預覽、中央文字與軌跡點仍完整保留；共用背景不可覆蓋或改變環的互動。中央白色球體以左上受光、右下收暗的連續霧面漸層，搭配寬幅內部明暗與外圈白色、季節色柔光建立飽滿體積；不使用內圈邊線、凹槽或盤面式結構。中央文字需維持比球面更深的對比。

## 全站與作品背景

- `.site-paper-background` 是進入網站後的唯一全域背景層，使用 `position: fixed`、`inset: 0`、`z-index: 0` 與 `pointer-events: none` 固定在可視區域；`main` 位於其上方且仍使用瀏覽器原生長頁捲動。
- 固定背景由 CSS 深色環境與 `.temporal-sculpture` 內嵌 SVG 組成。主環的大部分位於視窗外，只保留一段大尺度弧面穿過背景；環體改為較窄的霧面金屬帶，移除原本由粗虛線圓帽形成、近似機械零件的橢圓形段落。雙側細邊、材質分界與刻痕皆沿同一圓心與曲率建立，避免零散裝飾。
- 時間環包含 24 個等角度的實際 SVG 徑向刻痕，每格對應一個節氣；立春、立夏、立秋、立冬使用相同規則的稍長刻痕，並分別帶有低飽和霧青、淡金、暖銅與銀藍反射。刻痕嵌入環面且維持低對比，不顯示數字或名稱。
- 首頁時間環完全靜態：保留節氣環語言的雙側細邊、細亮刻度、固定指針與白色圓心，不顯示沿環運行的流光。標題主體僅以無邊界的局部明暗光場與文字亮度建立前後層次，不加入卡片或外框。
- 桌機內頁沿用首頁同一座靜態時間環、相同比例、24 刻度、固定指針與圓心，但把整體透明度降至 `0.44`，移除濾鏡與章節切換反應，使它清楚可辨、但仍只作為低於內容主體的固定背景。實際互動節氣環仍維持原本的自動輪轉，兩者不共享動畫或狀態。
- 背景時間環不再讀取 `followSolarTerm()` 的節氣索引，也不寫入 `data-season` 或進度變數；季節色只保留為環體本身的靜態材質反射。捲動、章節切換與節氣推進都不會改變背景時間環。
- 768px 以下的封面仍顯示同一座完整時間環；進站瀏覽後使用既有低成本固定環體，停用會建立超大離屏紋理的 SVG mask 與 24 刻痕，並把 SVG 繪製裁切在實際視窗內。手機內頁外觀待桌機方向確認後再統一，但背景同樣不執行季節回應或流光動畫。
- 大型時間環在桌機與手機都固定於同一位置，不再隨 `body[data-section]` 位移、縮放、變色或改變透明度；`prefers-reduced-motion` 不需額外收束背景動畫，因背景本身已是靜態最終狀態。
- `body` 以深靛藍作為 SVG 載入前 fallback。背景不使用 JavaScript 視差、全畫面即時 filter、大量粒子、星點或額外動畫套件；SVG 容器為 `aria-hidden` 且 `pointer-events: none`。
- 理時序、資訊章節、寄語標題與結語等主要內容使用深藍灰透明玻璃層；作品展示標題沿用相同的邊緣折光語言，作品舞台本身仍保留原有明亮呈現，使委託作品成為最高視覺焦點。桌機主要標題框統一使用 `--glass-frame`（上限 `1180px`），手機則統一為 `86vw`；章節小標題固定放在玻璃框內側頂端，後續增加的章節文字應置於既有標題容器內。前後分離依靠帶色透明面、適量背景模糊、細銀藍折光邊與局部香檳反光，不使用厚重黑影。手機的大型章節框不使用即時背景模糊，改以同一組透明深藍底色、折射漸層、邊框與內層高光維持玻璃層次；只有固定頂列與小型控制可保留低強度模糊。
- 桌機左側資訊軌整體採用克制的半透明寶石語言，不使用格線、斜向切割色塊或黑灰陰影營造分界。左列固定於背景之上，透過透明深藍色層、低強度模糊與藍橙粉彩色邊光維持主體滑動時的前後分離感。圓形選單移除集中式亮白反光，只保留均勻的深色玻璃面、細邊緣高光與兩枚藍橙、橙粉長菱形。章節書籤使用較深的半透明藍灰玻璃，搭配低彩度折射光、細銀藍邊與明亮霧白文字維持可讀性；上下小菱形仍為融合藍、橙、粉三色的切面晶石。書籤下方固定配置九枚切面寶石：上方三枚使用 `#8DB7DD` 藍、中段三枚使用 `#FCC26F` 橙、下方三枚使用 `#F3A4B0` 粉；三組之間不再插入圓點，改由一條與節氣指針同語言、穿過所有寶石中心的低亮度季節色光線串接。各色寶石皆保留亮面、深色切面與淡光暈，不以純色平塗。手機仍使用精簡的頂部列，不顯示這組裝飾。
- 理時序、觀芳華、繪春信、籌花事、寄語與謝花人皆為透明底層；原有資訊章節色暈、寄語整片漸層及章節上下背景邊線已移除，章節辨識改由標題、留白、細線與局部元件負責。
- 作品頁顏色來自 `src/data/seasons.js`，由 `script.js` 衍生為展廳色調陣列。
- 作品色只呈現在有邊界的 `.gallery-stage` 內。

## 文字可讀性

- 深色背景上的全域主要文字改用帶暖度的霧白，次要資訊採較低亮度的銀藍灰；內容與背景以明度及色相差建立對比，不依賴文字陰影。
- 理時序引文、寄語、委託名單與結語維持 400 字重；作品舞台若使用淺色底，仍沿用原本的深色文字規則，不強制改成白字。
- 正式作品若需要覆圖文字，需依該張構圖個別確認顏色與光影；不得沿用已移除測試圖的專屬規則。

## 音樂入口

- `<audio id="backgroundMusic">` 目前沒有 `src`，所以播放、靜音進入與提示皆隱藏。
- 加入正式音檔後，播放必須由使用者點擊入場或音樂按鈕直接觸發。
- 現有程式將音量在 1.8 秒內淡入至 0.22，失敗時顯示非阻斷訊息。
- 正式採用音樂前要確認授權與署名要求。

## 修改檢查

- 背景元素不可攔截點擊或鍵盤焦點。
- 固定層的矩形在捲動前後需維持貼齊視窗，桌機與手機皆不得產生水平溢出。
- 中央標題、副標與入口在常見尺寸保持清楚。
- 理時序與觀芳華的章節底層需和後續章節一致，節氣環與作品切換仍須正常。
- reduced-motion 下取消時間雕塑的章節轉場，維持同一穩定最終畫面。
