# 開場與背景

最後核對：2026-10-11

## 設計方向

整體以暖紙、低彩度四季色、淡墨、霧氣與柔光為主。裝飾集中於邊緣與角落，中央保留文案閱讀空間；避免過度鮮豔、硬邊、厚重陰影與「整張生成圖直接鋪底」的感覺。

## 開場封面

`#entrance` 是全螢幕原生 dialog，文案為：

- 主標：`霓影流轉 四時成章`
- 副標：`踏歲偕行續年華 來春共赴啟新篇`
- 入口：`入新章`

主、副標目前不含標點，不要自行補上。

背景採分層元素，而不是單一大圖：

| 元素 | 主要 hook | 內容 |
| --- | --- | --- |
| 紙與墨 | `.entrance`、`::before`、`::after` | 暖米漸層、SVG 雜訊紙紋、內緣墨暈 |
| 光與霓 | `.entrance-light`、`.entrance-iridescence` | 右上柔光與低彩度弧形霓光 |
| 局部畫意 | `.entrance-paint-*` | 使用保留原解析度的輕量版 `intro-atmosphere-v2.webp`，首屏完成後背景下載、解碼完成才套用；左上局部自行柔和融入，左下山河則與冬雪同步出現，避免提前暴露冬季象限 |
| 霧與連接 | `.entrance-mist-*`、`.entrance-cloud-bridge` | 橫向連接四季象限的柔霧 |
| 水紋 | `.entrance-water` | 只保留右下較不規則的淡波紋 |
| 春 | `.entrance-season-spring` | 左上枝條與 32 枚花形元素 |
| 夏 | `.entrance-season-summer` | 右上 7 道風線與 26 枚葉片 |
| 秋 | `.entrance-season-autumn`、`.entrance-bamboo` | 右下秋月、8 層雲霧與 16 株竹林 |
| 冬 | `.entrance-season-winter` | 左下 32 枚低彩度雪晶與冷色暈染 |

開場中央內容以 `translateY(clamp(24px, 5vh, 48px))` 稍向下配置。入口按鈕本體維持固定位置，JavaScript 只依指標距離改變文字強度與光暈。

四季象限在字體確定、封面開啟後，依左上春、右上夏、右下秋、左下冬的順序交錯融入。動畫只使用現有圖層的透明度，不增加素材請求或阻擋入口操作。

## 防止重新整理閃頁

- HTML 初始帶 `html.entrance-pending`。
- 此狀態隱藏 `.site-header` 與 `main`，並使用與封面接近的底色。
- 封面初始、開啟與關閉後都保留穩定的瀏覽器滾軸槽位，避免恢復頁面捲動時將置中畫面往左推移。
- JavaScript 開啟 dialog 後，在下一個 animation frame 移除此 class。
- 不要提前移除 class，也不要只靠 script 載入後才新增，否則會再次短暫閃出理時序。

## 理時序背景

- 理時序、觀芳華與後續章節都直接顯示同一個固定宣紙底層；章節本身保持透明。
- 理時序原有的漂移霧光、底部海波紋、四季飄葉與滑鼠推動效果已移除，不再建立額外的背景動畫或指標監聽。
- 節氣環本體、自動輪轉、指標預覽、中央文字與軌跡點仍完整保留；共用背景不可覆蓋或改變環的互動。

## 全站與作品背景

- `.site-paper-background` 是進入網站後的唯一全域背景層，使用 `position: fixed`、`inset: 0`、`z-index: 0` 與 `pointer-events: none` 固定在可視區域；`main` 位於其上方且仍使用瀏覽器原生長頁捲動。
- `body` 只保留 `#F7F2E9` 同色 fallback。背景本體使用較明亮的暖白宣紙、多層低對比漸層、四角淡彩水墨錨點與靜態 SVG fractal-noise 紙纖維；左下與右上另配置兩組不同輪廓的大型白花枝 SVG，枝葉固定於視窗邊緣，向內容區延伸時逐漸透明，不形成制式鏡像邊框。花枝及背景不使用 JavaScript、持續動畫或全畫面即時 DOM filter。
- 理時序、資訊章節、寄語標題與結語等主要內容使用低濃度暖灰粉褐透明玻璃層；作品展示標題與作品舞台暫時維持原有暖白色階。桌機主要標題框統一使用 `--glass-frame`（上限 `1180px`），手機則統一為 `86vw`；章節小標題固定放在玻璃框內側頂端，後續增加的章節文字應置於既有標題容器內，延續同一玻璃範圍。前後分離依靠透明底色、白色折光邊、輕微背景模糊，以及藍、粉淡光建立；不使用黑影或灰暗底塊。主要墨色與節氣環文字同步加深，以明亮背景和有色玻璃之間的色差維持對比。
- 桌機左側資訊軌整體採用克制的半透明寶石語言。三色融合出的暖灰粉褐 `#D4B4A9` 只作為低濃度環境色暈，底層仍以較亮、可透出後方紙面的中性暖紙色維持文字與元件對比；不使用格線、斜向切割色塊或黑灰陰影營造分界。左列固定於背景之上，透過透明色層、模糊與藍橙粉彩色邊光維持主體滑動時的前後分離感。圓形選單及章節書籤使用內外明暗與細亮面呈現鑲嵌感；按鈕內的兩枚長菱形分別使用與書籤晶石一致的藍橙、橙粉漸層。書籤內部以接近中性暖紙的半透明底色為主，只在中央保留極淡的 `#D4B4A9` 柔光，不設頂部白色光斑；深灰綠文字及帶有三色傾向的細邊框負責可讀性。書籤上下的小菱形為融合藍、橙、粉三色的切面晶石；右側與主頁交界由藍、橙、粉的透明晶邊及目前章節的三色切面晶石標記構成，不使用深黑縱軸。書籤下方固定配置九枚放大的切面寶石：上方三枚使用 `#8DB7DD` 藍、中段三枚使用 `#FCC26F` 橙、下方三枚使用 `#F3A4B0` 粉；圓點只放在三個色組之間。各色皆另有亮面、深色切面與淡光暈，不以純色平塗。手機仍使用精簡的頂部列，不顯示這組裝飾。
- 理時序、觀芳華、繪春信、籌花事、寄語與謝花人皆為透明底層；原有資訊章節色暈、寄語整片漸層及章節上下背景邊線已移除，章節辨識改由標題、留白、細線與局部元件負責。
- 作品頁顏色來自 `script.js` 的 `backgroundColors[24]`。
- 作品色只呈現在有邊界的 `.gallery-stage` 內。

## 文字可讀性

- 全域文字色集中為 `--ink-primary: #302A24`、`--ink-secondary: #5D5349`、`--ink-accent: #6A5948`；在參考最深紙色 `#E5D8C5` 上的對比約為 10.09:1、5.34:1、4.77:1。
- 理時序引文、作品一般說明、寄語、委託名單、結語及小型進度文字改用較深墨色；寄語與名單字重提高至 400。
- 第 9、15、22 張大圖上的專屬覆圖文字維持各自已確認的顏色與光影，不套用宣紙頁面的全域文字色。

## 音樂入口

- `<audio id="backgroundMusic">` 目前沒有 `src`，所以播放、靜音進入與提示皆隱藏。
- 加入正式音檔後，播放必須由使用者點擊入場或音樂按鈕直接觸發。
- 現有程式將音量在 1.8 秒內淡入至 0.22，失敗時顯示非阻斷訊息。
- 正式採用音樂前要確認授權與署名要求。

## 修改檢查

- 背景元素不可攔截點擊或鍵盤焦點。
- 固定層的矩形在捲動前後需維持貼齊視窗，桌機與手機皆不得產生水平溢出。
- 中央標題、副標與入口在常見尺寸保持清楚。
- 理時序與觀芳華的章節底層需和後續章節一致，節氣環與作品切換仍須正常。
- reduced-motion 下不顯示延遲載入的局部畫意層，避免純裝飾在解碼後突然跳入。

## 更新此文件的時機

修改開場、紙墨／霧／霓光、四季元素、全站或章節背景、節氣環周邊裝飾或音樂入口時更新。
