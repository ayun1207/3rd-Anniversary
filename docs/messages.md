## 現行圖片式輪播

- Vue 依 `src/data/messages.js` 的五頁資料產生 `.message-group`，統一管理頁碼、切換狀態、GSAP 動畫、觸控與放大視窗。`script.js` 只負責掛載元件，舊分組程式、事件監聽與重複狀態已移除。
- 現有五頁依序使用 `artwork-originals/27.png` 至 `31.png`；網站衍生檔位於 `images/messages/`，每頁提供 2400px 與 1200px WebP。
- 桌機圖片本身包含卡片、文字與署名排版。900px 以下改用 25 張獨立 WebP，依整頁圖量測的百分比位置與尺寸排列，原圖已包含傾角與陰影。手機 DOM 不建立整頁圖片。
- 左右箭頭、循環切頁、觸控橫滑、快速切換防護、`aria-hidden`／`inert` 與 `prefers-reduced-motion` 行為保留。
- 不同頁面的原始比例可以不同；輪播舞台由最高頁面穩定撐開，圖片保持完整比例，不裁切或拉伸。
- 手機每頁只載入當頁的 320px 縮圖，換頁前先準備下一頁五張圖。單張清晰圖最長邊 1200px，點擊時載入並解碼，成功後才開啟原生 dialog；周圍暗化，點空白處或按 Esc 退出，焦點回到原卡片。視窗內無拖曳與縮放手勢。
- 原圖放在 `artwork-originals/messages/01.png` 至 `25.png`。執行 `npm.cmd run optimize:message-notes` 產生 `images/messages/notes/` 的兩種 WebP 與 `src/data/messages.js`，資料檔由腳本產生。編號依目前各頁從上排到下排、同排由左至右對應；第三與第五頁為上三下二，其餘為上二下三。
- 位置量測以既有 `images/messages/27.webp` 至 `31.webp` 為參考。更新整頁排版後，需同步更新獨立原圖並重新執行上述指令。新增頁數時需擴充腳本的頁數與每頁上排數量。

## 現行檢查重點

- 五頁順序、首尾循環與狀態文字「第 X 頁，共 5 頁」正確。
- 桌機與手機不因頁面比例不同而讓外框或後續內容上下跳動。
- 圖片延遲至寄墨箋章節時載入；手機只請求獨立便條紙縮圖與點開的清晰圖，桌機使用既有整頁響應式圖。
- 檢查 25 張各自開啟、空白退出、焦點復原、五頁首尾循環、快速連點、手勢誤點抑制、斷點切換與 reduced-motion。圖片失敗或載入逾時後需解除切頁狀態，保留目前頁面並允許重試。

## 目前的四人分組輪播

- `.messages-track` 內每位參與者對應一張 `.message-card`，JavaScript 會依 DOM 順序每四張建立一個 `.message-group`。
- 一個視覺畫面最多顯示四人，使用兩欄、兩列且較緊密的交錯構圖，不做死板齊頭排列。
- 左右箭頭及觸控橫滑可切換前後一組；切換時四張玻璃卡會連同留言與署名整組橫向移動。新舊組保留安全間距，不使用透明度交疊，因此卡片顏色不會先亮後暗，文字也不會獨立跳換。首尾相接循環，但不自動播放，以免打斷閱讀。
- 桌機與手機箭頭都固定在輪播左右預留的安全區，不覆蓋卡片正文；手機保留 44px 觸控範圍。
- 所有分組共用同一個網格舞台與固定卡片高度，因此切換組別時，箭頭與後續內容都不會上下跳動。
- 人數可自由增加，組數由實際卡片數量自動推算；尾組不足四人時不補空卡，會依實際數量平衡位置。
- 若只有一組，左右箭頭隱藏；`prefers-reduced-motion` 下直接完成換組。
- 修改時需檢查末組與首組的雙向循環、快速連點防護、非目前組的 `aria-hidden`／`inert`，以及手機橫滑不攔截垂直捲動。

## 位置與用途

- `#messages-page` 位於籌花事與謝花人之間，是第 05 章；謝花人順延為第 06 章。
- 選單 key 為 `messages`，顯示名稱暫用「寄語」。
- 24 張卡片中已有 23 張由使用者填入寄語與署名；最後一張暫以「文字／署名」預留。修改正式內容時保留原文，不自行潤飾或改寫。

## 卡片結構

- `.messages-track` 內每位參與者對應一個 `<article class="message-card">`，載入後由 JavaScript 移入對應的 `.message-group`。
- 卡片內的 `<p>` 放留言，`<footer>` 放署名。
- 目前放置 24 張寄語卡，依 DOM 順序形成 6 組；內容仍可直接替換 `<p>` 與 `<footer>`，不需要修改 JavaScript。所有卡片正文與署名共用全站 LXGW WenKai TC 字型，不逐卡設定字型。
- 寄語外框使用比網站底色稍深的暖粉紙色；卡片以半透明米白為基底，利用淡青、淡米與粉色折射亮面及邊光做細微變化，不再使用三塊明顯實色底，不使用厚框、黑影或高彩度底色。
- `.messages-container` 的玻璃外框包住章節標題、全部字卡與輪播控制，作用與委託名單的整體內容框一致；不是只框住 `.messages-heading`。

## 可變人數與交錯規則

- 每組四張卡片使用兩欄兩列且完全等寬等高；順序固定為左上最高、右上明顯稍低、左下、右下再稍低，以較清楚的高低差形成交錯。分組後 `nth-child` 會在每一組重新計算，因此六頁套用相同排列。
- 桌機與手機皆維持四張卡片的雙欄兩列；560px 以下等比例縮小卡片、間距與內距，同一斷點內仍維持所有卡片相同尺寸。
- 固定高度依桌機、平板與手機分別設定，正式留言需完整容納且不裁切。
- 署名以卡片右下角為固定基準，不隨正文行數改變位置；卡片內保留署名安全空間，較長留言不得覆蓋署名。
- 寄語不是主視覺章節，桌機與手機都使用較緊湊的上下留白、固定卡片高度和組內落差；左右欄寬與兩側安全區仍維持對稱。
- 560px 以下改為緊湊的 2 x 2 交錯構圖，降低字級與內距；手機固定高度需容納目前最長留言，不裁切文字。

## 修改檢查

- 新增或刪除任意張卡片後，沒有重疊、水平溢出或不自然的大空洞。
- 留言長短不同時，每張卡片仍保持相同尺寸，署名停在卡片右下方，正文不溢出。
- 手機版文字完整可讀，卡片不超出視窗。
- 章節順序、選單 active、左側章名與右緣滑標同步為六章。
